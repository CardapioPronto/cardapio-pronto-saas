# Biblioteca de Temas Segmentados - Cardápio Digital

## 📚 Visão Geral

A biblioteca de temas agora inclui temas especializados para 7 tipos diferentes de restaurantes, além dos temas gerais tradicionais. Cada tema foi cuidadosamente projetado com cores, fontes e espaçamento otimizados para melhor representar o tipo de estabelecimento.

---

## 🍕 Temas por Segmento

### 1. **PIZZARIA** - Tema: "Pizzaria"
- **Cores principais:** Vermelho vibrante (#DC2626) + Laranja (#F97316)
- **Fundo:** Bege quente (#FEF3C7)
- **Fontes:** Bebas Neue para títulos (moderna, energética)
- **Uso:** Pizzarias, focaccerias, fornos
- **Características:**
  - Apetitoso e aconchegante
  - Sombras com toque de vermelho
  - Contraste alto para destaque
  - Arredondamento de 2xl para suavidade

---

### 2. **HAMBURGUERIA** - Tema: "Hamburgueria"

- **Fontes:** Fredoka One para títulos (moderna, jovem)
- **Uso:** Hamburgueria, fast food, comida rápida

## 🔄 Como Funciona a Seleção

1. **Por Tipo de Restaurante:**
   - Sistema sugere temas ideais baseado na categoria do restaurante
   - Cada segmento tem temas primários e temas alternativos

2. **Customização de Cores:**
   - Todos os temas permitem customização de cores
   - Ajuste fino sem perder identidade visual base

3. **Preview em Tempo Real:**
   - Aplicar tema e ver mudanças imediatamente
   - Menu digital atualizado com novo design

## 🚀 Implementação Técnica

### Novo Sistema de Segmentação

```typescript
// themes/menuThemes.ts

type RestaurantSegment = 
  | 'pizzaria' 
  | 'hamburgueria' 
  | 'sushi' 
  | 'cafeteria' 
  | 'sorveteria' 
  | 'bistro' 
  | 'bar'
  | 'outro';

// Obter temas recomendados para segmento
const pizzariaThemes = getThemesForSegment('pizzaria');
// Retorna: [{ name: 'pizzaria', theme: {...} }, { name: 'delivery', theme: {...} }]
```

### Componente de Seleção Segmentada

```tsx
import { ThemesBySegment } from '@/components/menu-digital/ThemesBySegment';

<ThemesBySegment />
```
